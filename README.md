# CoDrone Lite

Code, experiments, and projects for the **CoDrone Lite**.

This repository is a place to explore drone programming with the CoDrone Lite, starting with basic flight control and potentially expanding into automation, sensing, computer vision, navigation, and autonomous flight.

## Goals

* Control the CoDrone Lite programmatically
* Experiment with automated flight
* Explore sensors and drone data
* Build autonomous behaviors
* Experiment with computer vision and robotics
